# G8 source artifact and Windows dependency lock

NIN-31 now has a deterministic source artifact producer, separate from runnable release acceptance. Run `scripts/package-source.py --ref HEAD` with the D-local Python environment. Output is stored under `.finai/artifacts/source/<archive SHA-256>/` with a ZIP and matching manifest. `--verify <archive>` verifies it without relying on the current Git checkout.

The producer reads committed Git objects directly. Uncommitted edits, untracked files, ignored runtime data and local configuration are excluded. It refuses symlinks and submodules. The verifier checks member paths, sizes, modes, SHA-256, Git blob hashes, the reconstructed Git tree and the embedded commit object. This binds the archive to the named commit; it does not authenticate a signer or prove deployment approval. Identical source produces identical archive bytes. Existing content-addressed output is verified and never overwritten with different bytes.

The manifest lists dependency declarations, locks, migration inputs and external-runtime provisioning inputs. It explicitly records `runnable_release: false`, `sbom_complete: false`, and `NOT_BUILT_FROM_THIS_ARCHIVE`. These are source provenance records, not a complete SBOM or accepted Release resource. Tracked files are included as committed; this tool is not a secret scanner.

`services/api/requirements-local.lock` pins 56 external distributions for Windows AMD64 CPython 3.13.14, with artifact hashes. It preserves the 53 installed versions and explicitly selects hatchling 1.27.0 and trove-classifiers 2025.1.15.22 and editables 0.5 for local builds. Bootstrap installs wheel-only locked dependencies, then the editable API without dependency resolution or isolated build downloads. `httpx` is a runtime dependency because the managed observer imports it. Regeneration is an explicit operation using the reviewed D-local uv 0.10.8 executable; the file is not a Linux dependency lock.

Focused provenance tests cover deterministic output, dirty/ignored-file exclusion, tampered source and forged replacement hashes against the old commit, and symlink rejection. All 56 wheel hashes passed download validation. A fresh D-local environment installed the locked dependencies offline, built and installed the editable API with no build downloads, and passed pip check. The first isolated build exposed a missing editables build dependency; it was explicitly pinned before the successful retry. This editable check uses the current working source, not a pristine archive build. The running environment was not upgraded.

Remaining NIN-31 boundaries include a distributable API with migration resources, pristine application build provenance, complete runtime dependency/SBOM coverage, accepted canonical Release/Artifact records, and health-gated rollout/recall/rollback. The current dirty checkout contains integrated frontend changes absent from HEAD; this archive must not be represented as exact parity with that running UI. NIN-25 frontend acceptance remains separate and open.
