# Standalone web artifact

`scripts/package-web-artifact.py` collects a completed Next standalone build together with static assets and public files. Supply the materialized source directory, its verified source archive and a D-local output root. The expected entrypoint is `apps/web/server.js`. Tracing and Turbopack use the explicit monorepo source root, including when source is materialized inside another checkout.

Collection checks every tracked source file against the committed archive before and after packaging. Generated output does not substitute for that check. Dependencies must resolve within the recorded build roots; unsupported reparse points, escaping paths, directory cycles and duplicate destinations are refused. Standard Windows extended-length paths preserve the same containment requirement. The ZIP contains regular copied bytes with per-file hashes and a receipt identifying the original source commit and archive.

This collector verifies source inputs and collected output. It does not independently prove the earlier build invocation, dependency installation, absence of embedded environment values or runtime acceptance. Local credential files are excluded by name, and exclusions are recorded. Separate build and runtime evidence must identify this exact archive before a release claim can be considered. No canonical Release, deployment approval or completed SBOM is created by packaging.
