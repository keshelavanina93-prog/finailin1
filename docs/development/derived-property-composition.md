# Exact composition of reviewed derived properties

NIN-6 derived properties can now consume other reviewed properties through `{"op":"derived","property":{"resource_id":"…","version_id":"…"}}`. The existing deterministic expression evaluator handles arithmetic, text operations and lazy coalesce. There is no second calculation engine, replacement object identity or page-local formula authority.

Publication and execution share a bounded dependency resolver: at most 32 distinct property versions, depth 10, 100 expression nodes per property and 1,000 across the graph. Every dependency must be an exact approved DerivedProperty with its retained schema binding. Edges require the same exact schema, including hash. Self-dependency, cycles, conflicting versions of one property, mismatched schemas and missing retained edges are refused. Publication uses normal review, access boundaries and current-head concurrency fencing. Direct and transitive references become canonical resource dependencies; only real immutable pins are retained.

Per object/version, each property/version is evaluated once and shared within the graph. Results distinguish available, missing input, unavailable and not applicable. Coalesce records only the branches actually evaluated; a skipped fallback cannot poison an available value. A failed evaluated dependency does not become an inferred fallback value. Composed results retain the exact dependency values and the source fields actually read, including original object/version/hash, schema version, field name, missing/null/value state and value. Declared graph dependencies remain separate from evaluated input lineage.

Direct derived queries retain the graph and result through the existing content-addressed calculation store. Shared Functions bind the complete property graph in their execution plan and verify it again before execution. The result retains the identical graph and contributor values. Existing non-composed expressions keep their output contract. Current accounting and action authority remain separate.
