# Selected trace context in NYX

NIN-55 connects the visible trace selection to the existing resource inspection and retained lifecycle authorities. Graph responses must match the requested root and knowledge cutoff. Each selected visible node supplies its exact resource, version and graph cutoff; resource readback must match all three, including microseconds. Requests are bounded and cancelled when context changes. Results are keyed by authentication scope, company, trace root, selected node and cutoff so stale responses cannot become the active answer context.

While a trace is loading, unavailable, or its selection is hidden by a filter, NYX does not substitute the original resource, map object or work item. Closing the trace restores the original analysis context. Explicitly opening a version still navigates to that version. Answers retain their own exact references, so their Trace and History links do not silently follow later selections. This remains recorded-state explanation; model reasoning and financial performance claims are not added.
