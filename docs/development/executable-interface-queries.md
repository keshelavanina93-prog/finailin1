# Executable interfaces over retained canonical objects

NIN-6 interfaces now form reusable Object Set query roots. Previously the interface endpoint projected a page of values, but a subsequent search could query literal interface definition records and lose the implementation mappings. The same typed root now passes through the query API, saved ObjectSetDefinition, deterministic Function runtime, retained-input consumer and G8 ontology workbench.

The optional `ObjectSetQuery.interface` contains the exact interface resource/version and one to one hundred explicit implementation resource/version pairs. It requires `object_type: ObjectInterface`; ordinary concrete-type requests serialize as before. Each implementation must bind the selected interface version and its exact schema. Repeated identities, multiple implementations of one concrete type, mismatched semantic identities and incompatible reference targets are refused. Explicit static definition pins can postdate the requested data snapshot, consistent with saved historical queries; data valid/known time remains separate.

Common-field predicates are translated through each reviewed mapping inside the existing SQL query. Filtering occurs before the global count, sort and page, rather than by joining independently paged results. The first outgoing reference can use a common interface alias while following each original object's exact dependency version. Subsequent traversal uses the existing typed relationship compiler. Publication and runtime reuse the same interface substitution validation. Saved definitions retain the exact interface, implementation and schema dependencies with normal access checks and publication head fencing.

Results preserve canonical `objects` unchanged. `interface_bindings` records the common property contract and exact interface/implementation/schema versions; `interface_values` separately records the projection and its original object/version. Unfiltered objects with a changed source schema report `SCHEMA_CHANGED` and no projected values. Filtering or traversing incompatible roots explicitly fails instead of silently omitting records. Traversed endpoints do not receive an invented interface projection.

The shared TypeScript contract and Object Sets editor retain these pins, original root identities and all query steps across editing, saving and reopening. Common reference values use endpoint labels with exact references available on demand. Original object inspection, history and evidence drill remain available. This advances the advanced ontology workspace, not overall NIN-25 visual acceptance.
